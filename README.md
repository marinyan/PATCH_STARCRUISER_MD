# PATCH_STARCRUISER_MD

メガドライブ版『スタークルーザー』用のIPSパッチです。ROM本体は含まれていません。

## 対象ROM

- CRC32: `2B75B52F`
- SHA-1: `CB099ECDE141BEFFDFED6BB7F1D3DC6340DA81D1`

3本のうちいずれか1本を、未改造の対象ROMへ単独で適用してください。パッチ同士を重ねて適用する必要はありません。

## パッチ

### 1. バグ修正のみ

- `Star Cruiser - Bug Fixes.ips`

ゲーム仕様を変更せず、下記のバグ修正だけを適用します。

### 2. バグ修正＋旋回移動解除

- `Star Cruiser - Bug Fixes + Diagonal 3.ips`

バグ修正に加え、前後移動中の左右入力を有効化します。ゲームバランスを考慮し、前後移動中の旋回量は3に調整しています。

### 3. バグ修正＋旋回移動解除＋斜め平行移動

- `Star Cruiser - Bug Fixes + Diagonal 3 + Diagonal Strafe.ips`

2の内容に加え、Aボタン平行移動中の前後同時入力による斜め平行移動を追加します。これはオリジナル版で確認された仕様の復元ではなく、新規機能です。斜め平行移動の合成速度は正面・左右の平行移動と同じ大きさになるよう正規化されています。

## 共通のバグ修正

- 最初の模擬戦勝利後に発生し得るフリーズを推定修正
- 水星VOID基地で設計図を取らずに退出すると基地が爆発する進行不能を修正
- ゲートキーを同じ場所から複数回取得できる問題を修正
- ショットレーザーの4番目の管理枠が更新・解放されず、発射不能になり得る問題を修正
- 名前入力画面で初回リピート待ちが無入力中に切れ、方向入力が二重に処理され得る問題を修正

模擬戦後のフリーズは再現が非常に難しいため、静的解析に基づく推定修正です。

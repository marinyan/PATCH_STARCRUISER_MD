- CRC32: `2B75B52F`
- SHA-1: `CB099ECDE141BEFFDFED6BB7F1D3DC6340DA81D1`

すべて未改造の対象ROMへ適用してください。

## パッチ

- `Star Cruiser - Freeze Fix + Diagonal 3.ips`: 最初の模擬戦勝利後に発生し得るフリーズの推定修正＋斜め入力時の旋回量3

フリーズ修正は、模擬戦敵の撃破状態が実世界の破壊済みオブジェクト表へ残る問題を静的解析に基づいて修正したものです。再現が非常に難しいため、実プレイによる再現確認は行っていません。
